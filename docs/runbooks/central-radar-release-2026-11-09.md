# Central radar release — 2026-11-09

The PMMP redesign replaced result tables with `.tender_item` cards. The old reader returned zero records without reporting an error. This release restores collection and makes partial coverage visible while adding a sourced decision brief to each tender.

## Delivered behavior

- Stateful PRADO pagination uses the portal's advertised 50-record page size. Card and historical layouts remain supported. Full subjects, buyers, locations, deadlines, amounts and canonical consultation identities are retained.
- Thirteen procedure families cover the 28 advertised official choices, including architectural consultations/competitions, preselection, PPP, expressions of interest, quotations, competitive dialogue and reverse auctions. Harvested details retain the precise source wording/phase.
- Discovery and metadata refresh use separate queues. Discovery has a short recoverable lease; asynchronous reads and bounded writes keep the API responsive. Listing/detail requests share a serial gate and persisted cooldown. HTTP 433/403/429 stops requests; a maintenance page returning 200 is not successful collection.
- The radar reports live source state, last successful read, observed/declared counts, skipped rows, errors, delayed retry and manual synchronization. A failed inventory read has an accurate retry panel and retains authentication handling.
- The drawer shows a deterministic decision brief: available evidence, missing requirements/DCE/BPU, urgency, visits and practical next actions. It does not infer eligibility or profitability. Published categories and full subjects survive subsequent listing repairs and incomplete metadata responses.
- Real portal publication is distinct from ATLAS detection time. Verified zero amounts remain valid evidence. Architectural procedures are not suggested as confirmed construction-business opportunities.

## Operating limits

A capped, repeated, interrupted or skipped traversal stays partial; successful individual page reads are not presented as full catalogue coverage. The default bound is 200 × 50 records. Metadata refresh is asynchronous; the existing extraction/paid AI settings remain disabled. A visible missing DCE/BPU/qualification is a fact to resolve before deciding, not a fabricated summary.

## Official nightly closure

The [PMMP notice](https://www.marchespublics.gov.ma/pmmp/?lang=fr&page=plan) gives a daily access window from 07:30 to midnight, Moroccan time. The local continuous discovery worker holds its next job until opening. At midnight a discovery pass keeps the pages already imported and records `scheduled_closure`. The status keeps the most recent successful read visible, while the catalogue remains searchable. Manual radar sync returns the opening time during closure. The active detail refresh and BDC sweep also respect the window.
